# Farm Demo 🌻
Автономный тест фермы для Android. Персонаж выбирается свайпом. Изометрическая карта, посадка, сбор, продажа, стройка, премиум-декор. Сохранения локальные. Сервер, кошелек и платежи не подключены.

## APK
GitHub → Actions → **Build Farm APK** → Run workflow → скачать artifact **farm-debug-apk** после успешного запуска.

## Графика
Добавляйте согласованные изображения в app/src/main/assets/img/ с именами из assets/README.md. Интерфейс имеет резервные рисунки для недостающих PNG.

## Технология
Android WebView, Java + HTML5 Canvas (без сетевых запросов).
